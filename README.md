# 🚗 Automobile Sales Analytics Dashboard

An interactive dashboard built using **Python, Pandas, Plotly, and Dash** to explore automobile sales trends and understand how recession periods affect the automobile industry.

## 📌 Project Overview

This project visualizes historical automobile sales data through interactive charts. It provides two report views:

- **Yearly Automobile Sales Statistics**
- **Recession Period Statistics**

Users can select a report type and, for yearly statistics, choose a year to explore sales trends and advertising expenditure across vehicle types.

## 🎯 Objectives

- Analyze historical automobile sales trends.
- Compare sales during recession and non-recession periods.
- Examine automobile sales across different vehicle types.
- Visualize advertising expenditure by vehicle type.
- Explore the relationship between unemployment rates and automobile sales.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Plotly Express
- Dash
- HTML components through Dash

## 📊 Dashboard Features

### 1. Yearly Statistics

- Average automobile sales across years.
- Monthly automobile sales for a selected year.
- Average vehicles sold by vehicle type.
- Advertising expenditure distribution by vehicle type.

### 2. Recession Period Statistics

- Automobile sales trends during recession periods.
- Average vehicles sold by vehicle type.
- Advertising expenditure share by vehicle type.
- Relationship between unemployment rates, vehicle types, and automobile sales.
